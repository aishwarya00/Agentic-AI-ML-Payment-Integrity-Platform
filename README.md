# Agentic-AI-ML-Payment-Integrity-Platform
Human-in-the-loop AI for explainable healthcare payment-integrity claim triage.

ClaimSignal
ClaimSignal is a human-in-the-loop healthcare payment-integrity triage prototype. It combines claims-based pattern recognition, explainable anomaly scoring, transparent risk fusion, and evidence-grounded review summaries to help prioritize claims for analyst review.

Live demo: Streamlit app — coming soon

Overview
The project demonstrates an end-to-end workflow for identifying claims with atypical payment and multivariate patterns, organizing them into a prioritized review queue, and presenting the evidence needed for a human reviewer to investigate further.

Core capabilities include:

Provider billing-behavior segmentation and peer-group benchmarking

Expected-payment and payment-deviation analysis

Multivariate anomaly detection

Transparent ensemble risk scoring and review-priority tiers

Evidence-grounded, structured review summaries

A Streamlit dashboard for interactive claim-queue exploration

Safety and scope
This is a portfolio proof of concept built with synthetic/de-identified healthcare claims data. It is designed to support human review only.

It does not make clinical decisions or determine fraud, billing error, medical necessity, coverage, overpayment, payment action, or claim denial.
